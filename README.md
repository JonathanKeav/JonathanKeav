### Hi, I'm Jonathan 👋

I'm a senior .NET engineer and technical lead with 19 years of experience. I build high-volume systems that handle financial data, most recently call-record (CDR) billing for telecoms. I also hold a Master's in AI.

- **Architecture and cloud:** designed and led a hybrid, cloud-native Azure integration built on APIs, Service Bus queues, Functions, App Service and Azure SQL, drawing on event-sourcing ideas
- **Data:** SQL Server at large volumes, including query tuning, execution plans and indexing
- **Testing:** changed how my team tests, adding unit tests, containerised integration tests on every PR, and Playwright end-to-end tests
- **Delivery:** CI/CD with Azure DevOps and Octopus Deploy, with change-managed releases
- **Breadth:** DevOps, database administration, architecture, security advice and technical direction, and I'm a former team lead

**Outside work I build [Munificence](https://www.munificence.app)**, an expense management app for clubs and charities. It has AI receipt scanning, web and mobile apps in both app stores, and Stripe billing. I built and shipped it on my own, using AI coding assistants for much of the work. 👉 **[Read the case study](https://github.com/JonathanKeav/munificence-case-study)** for the architecture, the hard problems, and what I've learned building production software with AI.
